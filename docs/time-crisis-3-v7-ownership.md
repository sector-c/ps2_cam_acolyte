Original 0x10c460..0x10c51f (192 bytes, SHA-256 d8a2a77564afd116296eaa8082954cfbf688874649ac55c4e92407957e886bff) iterates three axes. Updates context+0xc4/0xc8/0xcc by adding velocities +0xd0/+0xd4/+0xd8; scales each new accumulator by remaining duration +0xdc and signed reciprocal division (~350) then adds to XYZ +0/+4/+8. Updates velocities by subtracting accumulator arithmetic shifts 4,1,3 respectively. No channel selectors or constants written. Initializer 0x10c520 seeds shake state and installs callback 0x10c460 at +0xc0. Dispatcher 0x10f9f0..0x10facf (224 bytes, SHA-256 219609b75e384257e86a57c6ba45ca048b62b35d0c8bdc52b4e38aff73f8af86) invokes primary callback at 0x10fa00, snapshots pose to +0x14..+0x27, invokes transient at 0x10fa60, decrements duration by five and clears +0xdc and +0xc0 on nonpositive expiry. Separate post callback at +0x9c remains independently guarded. No original instruction bytes committed.

## Standalone V7
- Fingerprint both original effect routines in addition to previous original transform/decoder checks.
- Track ownership requires same structural identity, monotonic main clock (not track cursor), exact held modes and last-written constants; allow only transient transitions among 0 and 0x10c460. Unknown effects remain refusal.
- Read saved pre-effect pose +0x14 and duration +0xdc in targeted PINE sample. Compare base target to saved pose and published matrices to visible displaced pose during shake.
- Keep explicit user activation intent separately from current write ownership. Suspend on replacement; poll read-only for two stable native candidates with advancing guest clock, matching packed channels/constants and matrices, recognized main callback, no post/transient effect. Re-run full activation with new native pose and recovery fields. Never reuse old world target after replacement. Attached path still requires a stable terminal sample and static inferred parent.
- Default no effect writes. Optional 'shake off' expires recognized active effect with one guarded u32 zero to +0xdc, only when base pose verified. Original dispatcher clears callback; cannot prevent previously rendered frames. 'shake on' allows future native effects. No code patches. Expired effect is not resurrected.
- 'disable' cancels pending reacquisition even without current ownership. Failed activation after attempted writes cancels automatic retry; transport/identity failure stops automatic writes. Unknown callbacks and stale held state refuse; no guarantee on non-atomic PINE races or identical-track reload.
